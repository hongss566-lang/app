# 알뜰 소비 탐정단 · 학생용 모험 배포 파일

교사 설정 없이 별명을 입력하고 1장부터 진행하는 8차시 수학 모험입니다.

- `allddeul-web.zip`: Netlify 업로드용. 압축을 풀어 `index.html`과 `assets`가 있는 `allddeul-web` 폴더 전체를 업로드합니다.
- `index.html`: 그림·글꼴·코드를 포함한 단일 실행 파일. 다운로드해 Chrome에서 열 수 있습니다.
- `allddeul-source.zip`: 수정 가능한 소스 코드 백업. 압축을 풀고 README의 실행 방법을 참고하세요.

학생의 기록은 사용한 기기·브라우저에만 저장됩니다. 각 수첩에서 앞 사건을 해결하면 다음 장이 열립니다.

검증: 단위 테스트 104개, 개인·모둠 1~8장 전체 플레이, 화면·접근성 107개, 오프라인 제한 프레임 검사 통과.
