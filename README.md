# 알뜰 소비 탐정단 · 학생용 모험 배포 파일

2026-10-21 업데이트: 교사 설정 없이 1~8장을 순서대로 해결하는 수학 모험입니다.

## 실행하기

`index.html` 파일 페이지 오른쪽 위의 다운로드(↓) 버튼을 눌러 저장한 뒤 Chrome으로 엽니다. HTML 안에 그림·글꼴·코드가 모두 들어 있습니다. 기존에 받은 파일은 자동으로 바뀌지 않으므로 새 파일을 받아 주세요.

- `index.html`: 학생이 바로 여는 단일 HTML 실행 파일입니다.
- `allddeul-web.zip`: Netlify용입니다. 압축을 풀어 index.html과 assets가 든 allddeul-web 폴더를 업로드합니다.
- `allddeul-source.zip`: 수정 가능한 소스와 테스트입니다. 압축을 풀고 README 실행 방법을 참고합니다.

## 이번 변경

1. 2장 물통에 전체 양·누적 L 눈금과 1L마다 굵은 선을 표시합니다. 6L ÷ ½L는 두 컵이 1L입니다.
2. 자연수·분수·대분수 선택과 분자·분모 숫자 칸을 제공합니다.
3. 버림·반올림 용어를 사용합니다. 반올림과 비교는 원래의 정확한 몫을 기준으로 합니다.
4. 확인한 단위·나눗셈 식·몫·반올림 가격을 비교할 때도 표로 보여 줍니다.
5. 선택 미션을 100mL당 가격 구하기로 바꾸고, 직접 입력·확인한 뒤 풀이를 공개합니다.
6. 마지막 미션에서 사건 해결로 이동할 수 있고, 남은 필수 활동을 누르면 바로 이어서 합니다. 음료·우유·주스 계산과 봉투 개봉을 마치면 4장(O)이 열립니다. 선택 미션은 건너뛸 수 있습니다.
7. 8장 수료 후 사건 해결 화면 맨 아래에 반짝시장 대모험을 추가했습니다. 캐릭터를 방향키·화면 버튼으로 움직이고 네 친구의 퀴즈를 풀어 단서를 모은 뒤 축제 문을 엽니다.

기록은 사용한 기기·브라우저의 수첩에 저장되며 기기 간 공유하지 않습니다. 같은 주소·브라우저의 이전 수첩도 이어서 읽습니다. 다운로드 파일은 저장 위치가 달라지면 브라우저가 별도 기록으로 처리할 수 있습니다.

검증: 단위 테스트 111개, 개인·모둠 1~8장 전체 플레이, 교사 기존 흐름, 기존 화면·접근성 107개와 새 화면 7개, 진행 오류 재현·복구와 최종 게임, 외부 연결·저장 없이 여는 제한 프레임 검사 통과.
