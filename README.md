# 알뜰 소비 탐정단 · 학생용 모험

2026-10-22 업데이트. 교사 설정 없이 1~8장을 순서대로 진행하는 초등학교 수학 모험입니다.

## 바로 실행하기

`index.html` 파일 페이지 오른쪽 위 **다운로드(↓)** 버튼으로 저장한 뒤 Chrome으로 엽니다. 그림·글꼴·코드가 HTML 안에 포함되어 있어 별도 설치 없이 사용할 수 있습니다. 새 파일을 받아 기존 파일 대신 열어 주세요.

- `index.html`: 학생이 바로 사용하는 단일 HTML입니다.
- `allddeul-web.zip`: Netlify용입니다. 압축을 풀어 `index.html`과 `assets`가 있는 `allddeul-web` 폴더를 업로드합니다.
- `allddeul-source.zip`: 수정 가능한 소스와 테스트입니다. 압축을 풀고 안의 README를 참고하세요.

## 이번 변경

1. 문제를 푸는 화면마다 상품 그림·양·가격을 함께 표시하고 새 사건으로 바뀔 때 안내합니다.
2. 흐름 카드를 손가락·마우스로 드래그해 순서를 바꿉니다. 놓을 위치와 번호를 표시하고 쉬운 설명을 붙였습니다.
3. 알뜰 선택 문장에서 ‘어림하기 전’을 뺐습니다. 실제 계산과 비교는 정확한 몫을 기준으로 합니다.
4. 스피드 라운드를 새로운 가상 상품·수치 다섯 문제로 교체했습니다.
5. 덜어내기는 쉬운 반 리터 예시부터 시작합니다. 두 상품 그림은 같은 눈금으로 보여 주고, 손계산 문제에도 상품을 다시 표시합니다.
6. 버그 기록 1~6은 모두 계산 과정을 먼저 보여 줍니다. 잘못된 단계와 고칠 원인을 찾아 수정합니다.
7. 오른쪽 **노트**에서 손가락·펜·마우스로 계산합니다. 지우개·실행 취소·다시 실행·전체 지우기가 있으며 개인/모둠별·장별로 자동 저장됩니다.
8. 보고서는 그림 사건 카드 선택 → 증거 자동 배치 → 내 설명 다듬기 → **보고서 봉인하기** 순서입니다. 사건을 바꿨다 돌아와도 수정 문장을 보관합니다.
9. 개인·모둠 모두 상품과 계산 증거를 보며 캐릭터 확인 문제로 마무리합니다. 학생 화면의 실제 친구 평가는 제외했습니다.
10. 우유팩·우유병에서 마신 양과 남길 양을 직접 봅니다. 같은 우유 사건의 표시는 A=900mL, B=2.3L로 통일했습니다. 이전 가족 선택은 실제 고른 상품을 보존해 읽습니다.
11. 수료증에 금색 증서 테두리·여덟 종류 배지·봉인·축하 캐릭터를 배치했습니다.
12. 마지막 게임은 별도 화면에서 시작합니다. 전신 2D 캐릭터가 팔·다리를 움직이며 걷고, 시장 친구에게 말을 걸면 상품 그림이 있는 문제 팝업이 열립니다. 문제 창에서도 노트를 사용할 수 있습니다.

## 마지막 게임 들어가기

8장 완료 → **사건 해결** → 수료증 아래 **마지막 모험 시작하기**.

방향키/WASD 또는 화면 방향 버튼을 꾹 눌러 이동합니다. 친구 옆에서 **대화하기**를 누르고 네 단서를 모아 축제 문을 엽니다. **수료증으로 돌아가기**로 나왔다 다시 들어가도 진행을 이어갑니다.

## 기록과 검증

기록은 사용한 기기·브라우저의 수첩에 저장됩니다. 기기 간 공유하지 않습니다. 같은 주소·브라우저의 이전 기록도 이어서 읽습니다. 다운로드 파일은 저장 위치가 달라지면 브라우저가 별도 기록으로 처리할 수 있습니다.

빌드, 단위 테스트 **115개**, 개인·모둠 1~8장 전체 진행, 기존 교사 흐름, 화면·접근성 검사, 터치 드래그·필기·지우기·저장 복원·보고서 수정 보존·게임 팝업 검사를 통과했습니다. 단일 HTML에서도 추가 파일 요청 없이 전체 기능을 확인했습니다.
